Help

遇到问题，按现象查

多数问题出在来源或网络上。按下面的现象对照着查。

首页看不到「猜你喜欢」或「为你推荐」

这两块需要有听歌记录或收藏才会显示歌曲。新安装时没有记录是正常的，先听几首歌或点喜欢，再返回发现页；不需要等待曲库分析完成。

榜单里的歌显示「曲库里没有」或放不了

榜单和在线歌单会对照资料库当前选中的来源。先到「资料库 → 曲库」检查是否选中了存有这首歌的飞牛、WebDAV、Emby 或 Plex 来源，再返回重试；曲库没有时，还需要可用的自备音源插件来在线播放。

WebDAV 连续播放中途停住

1.3.52 已修复 WebDAV 连续播放过程中可能停住的问题，请先确认使用 1.3.52 或以上版本。仍出现时，检查连接和网络，并从「设置 → 诊断日志」导出记录。

暂停很久后继续播放没有动静

1.4.33 起，暂停超过一分钟再继续时会重新准备歌曲并回到原位置；短暂停后进度没有前进也会自动重试一次。仍不能播放时检查网络和歌曲来源，在播放页重试当前来源。

WebDAV 还要手动刷新索引吗

先设置资料库根并建立一次索引。1.4.34 起回到 App 会自动检查已有曲库的变化；连接不可用、正在扫描或刚检查过时可能不会立即更新。需要马上重试时，仍可打开这条连接的资料库点「刷新索引」。

阅读外网地址出现红字

提示「请填 https 开头的地址」时，检查是否使用 HTTPS；提示「只填到域名」时，删除域名和可选端口之后的路径。复制地址时附带的 #、? 或末尾 index.html 会自动去掉。

Emby 登录失败

确认 Emby 服务正在运行，服务器地址、端口及 HTTP 或 HTTPS 选项与服务一致；核对用户名和密码，并先用同一账号在 Emby 中登录。使用 HTTP 时按页面提示确认后重试。

地址或账号修改后重新点「添加」；仍失败时，在「设置 → 诊断日志」查看提示，分享记录前检查是否含个人信息。

WebDAV 的封面显示成占位图

如果改过歌曲标签后，文件内的封面变成了占位图，1.3.25 起汐月会在读取封面时尝试自动恢复。仍然不显示的话，可以重新建立索引后再打开歌曲页；再有问题，到「设置 → 诊断日志」导出日志。

设置 WebDAV 资料库目录时提示未完成

1.3.22 起，个别过大的封面或歌词读取失败，不会再让整次索引作废。仍然提示「资料库根设置未完成」时，到「设置 → 诊断日志」导出日志，里面会记录失败原因。

Emby、Plex 的数量显示「—」

如果是暂时读不到，稍等片刻后重新进入资料库，或回到 App，汐月会自动重试失败的项目。服务器不提供总数时会继续显示「—」；歌单总数目前也可能不显示，这不代表里面没有音乐。

某一首歌放不了

放不了的歌会自动跳到下一首（连续最多三次），并留下日志。先看是不是只有这一首有问题，再看它的来源是否可用。

开了代理就放不了

使用 Surge 等假 IP 模式的代理时，确认汐月和音源的请求没有被拦截。第一次配置容器面板时，请在家里用内网地址打开，并暂时关掉代理。

酷我无损或 APE 放不了

某些音质平台实际拿不到时，汐月会自动降一档。飞牛里的 APE 需要服务器转码，先确认飞牛自己的 App 能播放同一首。

歌单只导入了一部分

平台可能只公开一部分歌曲，私密或过期的分享也读不到。汽水音乐的歌需要在 QQ 音乐、网易云里配对，配不上的会列在结果里。

容器连不上，或体检没有结果

确认容器在运行，App 里填的端口和 compose 里映射的端口一致；出门在外要用 HTTPS 外网地址。体检需要先连接飞牛曲库。
