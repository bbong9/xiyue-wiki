Sources

家里的曲库，随身听

把 NAS、媒体服务器和在线音源，接到同一个播放器里。

飞牛、WebDAV、Plex、Emby

飞牛音乐是原生连接，可以按歌曲、专辑、歌手、风格和歌单浏览。WebDAV 适合任何 NAS，会识别目录里的封面和歌词文件。Plex、Emby 用各自的服务器账号连接。

所有来源都在「设置 → 账号与来源」里添加和管理。连接好的 WebDAV、Plex、Emby，也能从资料库的「曲库」直接进入浏览；WebDAV 需要先建立索引。

1. 在页面的「添加媒体库」选择飞牛音乐、WebDAV、Plex 或 Emby，填写你自己的服务器连接资料，按页面提示完成添加。

2. 已添加的连接在上方单独列出。要修改地址或连接资料，点该行旁的编辑按钮，或长按连接选「编辑」，修改后保存。

3. 要移除连接，长按该行选「删除」并核对确认提示；只移除汐月里的连接及相关本机资料，不会删除服务器上的音乐。

在家走内网，出门走外网

每个来源都可以同时填内网和外网地址。在家时自动走局域网，又快又省流量；出门后自动切到外网，正在播的队列不受影响。

添加 Emby

1. 打开「设置 → 账号与来源 → 添加媒体库 → Emby」，填写服务器地址、端口、用户名和密码；名称可以留空。内网使用 HTTP 时，先阅读并确认页面提示。

2. 点「添加」，汐月会先验证登录。失败时检查服务器是否运行、地址和端口是否正确，以及该账号能否在 Emby 中登录；修改输入后再重试。服务器地址不要带浏览器页面的 #、? 或 index.html。

添加 Plex

1. 在「添加媒体库」选择 Plex，点「打开 Plex 授权页面」，在浏览器登录并确认，回到汐月选择服务器。

2. 也可以选「手动填写服务器地址」，输入服务器地址、端口及服务器的访问令牌；使用 HTTP 时按页面提示确认后添加。

3. 添加完成后，到「资料库 → 曲库」选择这台服务器；有多个音乐库时，再选择要浏览的音乐库。

开着代理也能听

开着 Surge 这类代理工具时，汐月能正确判断你是否在家，在线音源也能正常播放。

i

如果还是放不了，先确认音源本身可用，再检查代理规则。

飞牛转码

APE 等手机不能直接播的格式，会请飞牛转码后再播放，稍等片刻即可。

在线音源与家里音源

手机上的音源由你自己导入；家里音源放在汐月容器里，登录汐月账号即可使用。手机这边解析不出来时，容器会接手。

浏览 WebDAV 与建立索引

1. 在「设置 → 账号与来源」长按一条 WebDAV 连接，选「浏览文件」可以逐层查看目录；要把音乐纳入曲库，选「设置资料库」，已有曲库时则选「打开资料库」。

2. 进入资料库后点「资料库根」，进入存放音乐的目录，点「设为资料库根」并等待建立索引。这里选的是要浏览、检索的音乐范围。

3. 已建立索引后，回到 App 时会自动检查 WebDAV 曲库变化；连接不可用、已有扫描进行或刚检查过时，可能需要等待。也可在这条连接的资料库中点「刷新索引」；尚无可用索引时按钮显示「开始索引」。扫描中可按页面按钮暂停、继续或取消。

4. 要换音乐范围，再点「资料库根」选择新目录并确认；完成后到资料库切换到这条 WebDAV 来源，按歌曲、专辑或歌手浏览。

扫描会同时读取多个目录；遇到服务器限流、超时等情况时会放慢，歌曲顺序仍保持稳定。

设置默认下载库和目录

1. 添加 WebDAV 后，在「账号与来源」页面下方的「默认下载库」选择一条连接；选「每次选择」则在下载时再选。也可长按 WebDAV 连接，点「设为默认下载库」。

2. 长按目标 WebDAV 连接，选「默认下载路径」，再点下载目录，进入想保存新歌的文件夹并选定，最后点「完成」。每条 WebDAV 连接可以使用不同的目录。

3. 「资料库根」决定索引哪些音乐，「默认下载路径」决定把新歌写到哪里，两者都从这条 WebDAV 连接的根开始选择。想让新下载的歌进入这份曲库，请把下载目录选在资料库根内。

选择 Emby、Plex 的音乐库

1. 先在「账号与来源」添加服务器，再从「资料库 → 曲库」选中对应的 Emby 或 Plex 来源，打开歌曲、专辑等浏览入口。

2. 同一服务器有多个音乐库时，页面上方会出现「音乐库」选择器，点它选中要听的库，再切换歌曲、专辑、歌手或歌单；只有一个音乐库时不显示选择器。

3. 在页面搜索框输入关键词，查看当前所选音乐库的结果；要换另一库，清空关键词并重新选择音乐库。

进阶

WebDAV 证书：连接提示证书不受系统信任时，点「查看证书」，核对服务器与证书后再决定是否「信任并保存」；这里只信任这张证书，证书变化后需要重新核对。

维护自备音源插件：在「设置 → 音乐源 → 用户来源包」可使用自己取得的链接导入，重复时按提示替换或保留已有版本；有权限预览时先核对再确认。已安装项可启用、停用、删除，支持更新的项目会显示更新入口。
